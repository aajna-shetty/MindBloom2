# PART 4 — QUESTIONNAIRE MODULE

Inspect and reuse the existing questionnaire.

Implement the complete workflow:

1. Retrieve questionnaire questions.
2. Validate responses.
3. Store responses.
4. Execute the actual scoring algorithm.
5. Calculate total score.
6. Calculate maximum possible score.
7. Apply documented scoring thresholds.
8. Return the screening classification.
9. Persist results.

For a conventional weighted questionnaire, the general scoring structure is:

\[
S_Q=\sum_{i=1}^{n}w_i x_i
\]

For reverse-coded items on a scale from \(a\) to \(b\):

\[
x_i'=a+b-x_i
\]

For a normalized score, when appropriate:

\[
P_Q=\frac{S_Q}{S_{Q,\max}}\times100
\]

These are general formulas only. Implement the actual questionnaire's official scoring rules, including reverse-coded items, weights and missing-response handling.

Do not invent the questionnaire cutoff.

Record the questionnaire name, version, scoring method and threshold source.

For a calibrated classifier:

\[
p=P(ASD\mid X_Q,X_V)
\]

where:

- \(X_Q\) = questionnaire features.
- \(X_V\) = video features.
- \(p\) = calibrated model probability.

Apply a validated threshold \(T\):

\[
Classification=
\begin{cases}
\text{Above screening threshold}, & p\geq T\\
\text{Below screening threshold}, & p<T
\end{cases}
\]

Return the actual probability, threshold, model version and classification.

### Case B: No suitable combined model exists

Inspect whether a participant-level labeled dataset is available.

If sufficient valid data exists, implement a reproducible model-training pipeline.

Compare suitable models:

- Logistic Regression.
- Random Forest.
- XGBoost, if available and justified.

Use questionnaire and video features together.

Use participant-level splitting to prevent leakage.

Evaluate:

\[
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
\]

\[
Precision=\frac{TP}{TP+FP}
\]

\[
Recall=\frac{TP}{TP+FN}
\]

\[
Specificity=\frac{TN}{TN+FP}
\]

\[
F1=2\frac{Precision\times Recall}{Precision+Recall}
\]

Also evaluate ROC-AUC, calibration, confusion matrix and sensitivity/specificity trade-offs.

Select the decision threshold using validation data and document the selection method.

Do not simply use 0.5 without justification.

# PART 7 — VIDEO FEATURE STATISTICS AND EMOTION AGGREGATION

Reuse existing feature calculations wherever available.

Verify the following examples against the implementation.

Mean:

\[
\mu=\frac{1}{N}\sum_{i=1}^{N}x_i
\]

Variance:

\[
\sigma^2=\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2
\]

Standard deviation:

\[
\sigma=\sqrt{\sigma^2}
\]

Blink rate:

\[
BlinkRate=\frac{N_{\text{blinks}}}{T_{\text{minutes}}}
\]

EAR:

\[
EAR=\frac{\|p_2-p_6\|+\|p_3-p_5\|}
{2\|p_1-p_4\|}
\]

For ViT emotion probabilities:

\[
\bar p_j=\frac{1}{N}\sum_{i=1}^{N}p_{ij}
\]

Emotion distribution:

\[
D_j=\frac{N_j}{N}\times100
\]

Only successful ViT inferences may contribute to the emotion statistics.
